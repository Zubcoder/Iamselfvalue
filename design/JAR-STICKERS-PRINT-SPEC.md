# Наклейки на банку «Апельсиновый джем — «Твоё наслаждение»»

Банка: стеклянная шестигранная 100 мл, высота 65 мм, ширина 70 мм (по углам), крышка твист-офф ~48 мм.
QR-код на обеих наклейках ведёт на бота: https://t.me/Open_your_inner_sun_bot?start=orange_jam

## 1. Наклейка на крышку — `jar-sticker-orange-print.png`

| Параметр | Значение |
|---|---|
| Форма | круг |
| Размер по обрезу | Ø 45 мм |
| Вылет под обрез (bleed) | 3 мм с каждой стороны (файл Ø 51 мм) |
| Безопасная зона | 5 мм от края |
| Разрешение файла | 300 dpi, 601 × 601 px, PNG с прозрачным фоном вне круга |
| Материал | самоклеящаяся плёнка/бумага, матовый или soft-touch ламинат |
| Тираж | по количеству банок |

## 2. Наклейка на банку (бок) — `jar-body-label-print.png`

| Параметр | Значение |
|---|---|
| Форма | прямоугольник со скруглёнными углами (радиус ~2 мм) |
| Размер по обрезу | 60 × 35 мм (клеится на две соседние грани, сгиб по ребру) |
| Вылет под обрез | 2 мм с каждой стороны (файл 64 × 39 мм) |
| Безопасная зона | 4 мм от края |
| Разрешение файла | 300 dpi, 754 × 459 px, PNG |
| Материал | самоклеящаяся плёнка (влагостойкая), матовый ламинат |

Если типография может печатать только на одну грань (35 мм), попросить пропорционально уменьшить до 30 × 35 мм — QR ≥ 15 мм остаётся читаемым.

## 3. Цвета (для цветопробы)

| Элемент | HEX | RGB | CMYK (ориентир) |
|---|---|---|---|
| Фон, центр (фиолетовый) | #423189 | 66 49 137 | 85 90 0 15 |
| Фон, край (изумрудный) | #105040 | 16 80 64 | 85 35 70 45 |
| Золото (текст, рамки) | #D4AF37 | 212 175 55 | 15 25 90 5 |
| Белый (текст, подложка QR) | #FFFFFF | 255 255 255 | 0 0 0 0 |
| QR-код | #000000 | 0 0 0 | 0 0 0 100 |

Фон — радиальный градиент от фиолетового (центр) к изумрудному (край). Печать CMYK, цветопроба по золоту обязательна: не должно уходить в жёлтый/зелёный.

## 4. Требования к QR

- Не масштабировать QR отдельно от макета; минимальный размер QR — 15 мм.
- Не печатать QR на металлике/глянце без ламината — блики мешают считыванию.
- Проверить считывание с тестового отпечатка телефоном перед тиражом.

python3 design/generate_jar_sticker.py
